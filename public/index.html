The idea: a waterfall

Each column has several sources, always asked in the same order. If the first one has nothing, the next one is asked. The first answer wins and the rest are skipped. Here is the column “Email provider”:

  1. 1MX recordWhere the company’s email is delivered. Usually names the provider directly.
  2. 2SPF recordAsked only if step 1 found a spam filter or an unknown server. Lists who may send mail for the company.
  3. 3MX host as-isLast resort: show the raw mail server, so the cell is never silently empty.

In paid tools every source costs credits, so the order saves money. Here every source is free, so the order is about trust: the most reliable source goes first. The small number in each cell shows which step answered. Click any cell to see the whole chain.

How I build these for clients

Every cell names its source.
A rep who cannot tell where a number came from will not trust the list. The source and the evidence travel with the value, all the way into the CSV.
Missing data is not a no.
“No CRM visible” is not the same as “does not use HubSpot”, and finding Salesforce does not rule HubSpot out. A DNS verification record shows a HubSpot account, so the cell says “HubSpot signal found”, but the rule “Uses HubSpot” stays open until a script or mail record proves it. A company is never ranked up or down on a guess.
Clean the list before you pay for it.
Duplicates in a different spelling are caught before any lookup runs. Duplicates that only show after a redirect are caught after. Broken rows are marked, not dropped.
The model writes. Rules decide.
The language model only drafts one opening line. Filtering and ranking are fixed rules you can read. Every number in the line must match a fact in the row, both the value and what it counts: “20 offices” fails when the row says 200 employees. If a claim cannot be backed, or the model is down, a template writes the line and the cell says so.

The sources

The company homepage
Read once per row. Script addresses reveal tools such as HubSpot, button texts reveal the sales motion. Sites that block automated visitors are respected and fall through to the next source.
DNS, over HTTPS
MX, SPF and verification records from Cloudflare’s 1.1.1.1, with Google’s resolver as the fallback. Public by design, free, no key.
Wikidata
Matched on the company’s official website, never on its name, so a namesake cannot slip in. Gives country, headcount and LinkedIn page when someone has entered them.
Workers AI
Cloudflare’s free tier with a hard daily limit. Writes the opening line from the facts in the row and nothing else.
